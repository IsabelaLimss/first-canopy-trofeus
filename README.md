# FIRST CANOPY — Concurso de Troféus

Projeto do formulário de submissão de propostas do FIRST CANOPY, preparado para publicação no Cloudflare Pages.

## Estrutura

- `index.html` — página principal
- `styles.css` — estilos
- `app.js` — validações e interação do formulário
- `_worker.js` — backend para envio da proposta
- `assets/` — logos e fundo topográfico

## Cloudflare

Conecte este repositório ao Cloudflare Pages. O arquivo `index.html` está na raiz.

A configuração de armazenamento D1/R2 e do envio de e-mails pode ser adicionada posteriormente sem alterar o layout do formulário.
